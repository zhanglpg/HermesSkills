# GPS 轨迹采样与稳健校准方法

模型给初值，轨迹给真值。校准的目的：把"纸面推算"钉到"真实人群的真实速度"上，同时避免被个别极端轨迹带偏。

## 一、样本采集

### 来源优先级
1. **两步路（2bulu.com）**：活动帖（d-xxxxx，常带计划口径）与游记帖（mc/community/detail?id=xxx，常带 GPS 三件套：总里程/运动耗时/累计爬升）。⚠️ 详情页反爬 403 —— 用百度/必应搜索摘要提取（搜索式：`两步路 <山名> 轨迹 km 耗时`、`site:2bulu.com <山名>`），摘要数字**原样抄录**
2. **8264 游记**（youji/xxxx）：常含分段时刻与轨迹截图数据
3. **美篇/知乎/微博/小红书**：个人 GPS 记录（美篇打点式游记常含"距离起点 x.xkm 当前海拔 xxxx"格式）
4. **赛事路书**（越野赛官方）：距离/爬升为勘定值最准，但**耗时是关门时间/精英成绩，不代表徒步人群**
5. 商业队/俱乐部活动帖：计划口径（"预计 X 点到达"），代表大众节奏下限

### 每样本必录字段
路线与区段（起终点精确到村/牌坊）｜距离｜用时（**注明总时间/运动时间**）｜累计爬升｜日期（季节！）｜人群标签（商业队/俱乐部/个人强驴/重装/速穿/新手/冬季）｜来源 URL｜获取方式（全文/摘要）

## 二、离群剔除规则（先剔后算）
**必须剔除**（不进中位数）：
- 越野跑/速穿纪录（速度 >4.5 km/h 且爬升密度 >60 m/km 的样本）
- 冬季冰雪/暴雨极端天气样本（单独记录为"恶劣天气修正依据"）
- 重装多日（>10kg 且跨夜）——除非目标就是重装估算
- 新手/夜爬/含长时间摄影的样本（可单独记录为"下限参考"）
- 未完成/中断轨迹、纯分段（分段样本用于分段校准，不进全程中位）
- 含大量景区排队的样本（排队时间单独剥离为刚性加项）

**保留但降权**：商业队计划口径（代表大众下限）、"总时间"口径样本（比运动时间大 10–25%，换算时注明）。

## 三、稳健统计
1. 单轨速度 = 距离 ÷ 用时（统一口径；总时间样本 ×1.15 近似换算为运动时间，或分开统计）
2. **中位数**为基准（n≥3）；n=2 取区间；n=1 标"孤证·低置信"
3. 报告分布：min / 中位 / max + n + 剔除清单（可审计）
4. 爬升数据噪声 ±300m 常见（气压计 vs 地图插值），以多源重叠区间为准，不取单轨精确值

## 四、人群换算（轨迹人群 → 目标队伍）
必须有一个**锚定线**：目标队伍在某条同时有轨迹样本的线上的实测成绩。
```
换算系数 k = 锚定线轨迹中位耗时 ÷ 目标队伍锚定线实测耗时
目标队伍预计耗时 = 目标线轨迹中位耗时 × k
```
已建立的锚定（本工作流默认）：
- 锚定线 = 峨眉山南线（99 道拐，24km/+3000m）；基准队伍实测 9–10h（中值 9.5h）
- 峨眉山轨迹人群：普通游客 12–16h、强驴 10–12h → **基准队伍 ≈ 强驴轨迹人群上限**
- 商业队/俱乐部中位 × 1.2–1.3 ≈ 基准队伍（由宜兴/白马尖/千八多线交叉验证）
- 无锚定线数据的新队伍：先走一条本地成熟线（如杭州标毅线）实测，再启用本模型

## 五、模型 ↔ 轨迹互验与勘误
- |T_model − T_track中位| / T_track中位 ≤ 15% → 采用两者交集区间
- >15% → **以轨迹为准**，回查 T 级构成/爬升密度是否判错，输出勘误（旧值→新值→依据）
- 无轨迹变体线：用"同域同 T 级路线的速度"类比推算，输出必须标"模型推算·低置信"，并列出最快获得样本的方法（两步路搜轨迹号）
- 每次发布后收到新样本 → 增量更新中位数 + 出勘误记录，**不静默改数**

## 六、单日可行性判定（配合强度）
1. 昼长校验：采用耗时中值 + 1h 余量 < 出发时刻至日落时长（9 月华东日落 ~18:15；12 月 ~17:00）
2. 关门校验：末班索道/景交/高铁时刻倒推最晚下撤点，写入"关门纪律"
3. 超昼长 → 三选一：前晚就位提早出发（仍超则否决）／拆多日／降级变体线
4. 输出格式：`✅ 单日可行（标准玩法：前晚就位 X 点开走）` / `⚠️ 单日极限（条件：…）` / `❌ 单日不可行（依据：…）`
