# T1–T5 技术难度分级详表

分级依据**可观察特征**（游记原文、轨迹照片描述、路况引文），不凭"野路/景区"标签。一条线按路段拆分定级，给出各 T 级里程占比。

## 分级定义与判据

### T1 成熟石阶 / 栈道 / 铺装
- 判据：人工砌筑台阶、木/石栈道、水泥路；路面确定，速度仅由坡度决定
- 强驴参考：平/缓 3.0–4.0 km/h；爬升 300–350 m/h；下降 450–550 m/h
- 例：峨眉山石阶、黄山全程、三清山栈道、明月山 6281 级、武功山金顶→大门万级台阶、标毅线 90% 石板段
- 注意：**长陡石阶（>45°连续）实际爬升率可低至 250–300 m/h**（如明月山石阶段普通人 4–5h/6.3km）；"台阶多"本身是耗时项不是难度项

### T2 清晰土路 / 草甸主线 / 成熟古道
- 判据：踩踏充分、路迹明显、无需辨认；高山草甸脊线、古道石板、防火道（平缓段）
- 强驴参考：3.2–4.0 km/h（**全分级最快**）；爬升 330–380 m/h
- 例：武功山发云界—金顶草甸脊（3.2+ km/h，但注意横风）、宜兴古道村道段、白马尖南线古道（"很好走、路径清晰"）、十里琅珰游步道
- 反直觉要点：**成熟"野路"（名义上非铺装）常常比石阶陡坡更快**——不要把 T2 当折扣项

### T3 野路路迹清晰
- 判据：有路迹 + 飘带/路牌/轨迹可辨，偶需在岔口辨认；碎石树根路面、竹林小道（踩踏明显）
- 强驴参考：2.3–3.0 km/h；爬升 280–330 m/h
- 例：武功山龙山→发云界（"路牌密集，绝对不会走错"但碎石树根 20–30°持续坡）、九华南段（2025 后飘带十来米一条）、千八林间段、武明草木分界段、宜兴大部分竹林段
- 判级要点：飘带密度是硬指标——"十来米一条"= T3 上限（近 T2）；"间隔百米+岔路多"= T3 下限

### T4 受阻野路
- 判据（满足其一即 T4）：乱石坡/石海需翻行；滑坡体/泥石流痕迹；烂泥速降；60°+ 陡坡需手脚并用（含抓铁链/树枝）；路迹模糊需频繁对照轨迹；灌木/箭竹钻行；需自主开路
- 强驴参考：1.2–1.8 km/h；爬升 200–280 m/h；下降 250–350 m/h（"下山比上山快不了很多"）
- 例：九华打鼓岭石海（"重装者噩梦"）、九华南脊野线（6.8km/近6h=1.2 km/h，含 3 处垂直攀爬）、白马尖天河尖方向（"几乎看不见路、大石头翻行"）、宜兴"叶子"段（60–70°竹坡攀竹）、武明羊狮幕乱石段（"四驱"）、绝望坡碎石 70°（短段）
- 判级要点：游记出现"手脚并用/四驱/披荆斩棘/看不见路/翻行"字样 → T4

### T5 技术段
- 判据：需绳索辅助攀爬/下降；暴露刃脊（两侧悬崖）；岩壁攀登
- 强驴参考：0.6–1.0 km/h；需额外安全时间与装备
- 例：九华狮子山绳索段（2026-03 绳断伤人事故点）、青龙背（官方劝离）、天都峰新道口 60–80°+鲫鱼背 85°（有扶手/绳但属 T4–T5 边界，排队另计）、天柱峰野攀（禁止）
- 判级要点：T5 段通常很短（<1km），但对时间和风险的影响不成比例；带新手时按 ×2 时间计

## 特殊修正因子
| 因子 | 修正 | 依据 |
|------|------|------|
| 下降密度 >100 m/km | 下降速率成主约束；总时 +10%（膝疲劳递减效应）；强制护膝双杖 | 武明 B 线 ↓3300m |
| 高海拔 >2500m | 爬升率 ×0.85（3000m+ ×0.75） | 一般高原经验 |
| 夜间/头灯段 | 该段速度 ×0.7 | 夜爬实测普遍值 |
| 雨雪后 2–3 天 | 全线 ×0.8 或改期（竹叶/石阶/乱石极滑） | 各线事故记录集中于雨后 |
| 冬季冰雪 | ×0.6–0.7 + 冰爪；或改期 | 武功山冬季 13h+ vs 夏季 9h |
| 重装（>12kg） | ×0.75–0.85 | 8264 重装样本对照 |
| 景区排队/预约 | 刚性加项（0.5–3.5h，节假日取上限） | 黄山天都峰 1h40 排队、莲花峰 3.5h 实录 |
| 蚂蟥/蛇虫季钻林段 | 心理减速 ×0.9 + 扎裤脚时间 | 赣西/浙南梅雨季 |

## 定级操作流程
1. 从游记/轨迹引文中摘录路况原句（带来源）
2. 按判据给每段定级，产出"T 级构成表"（各级里程占比）
3. 计算加权速度 v_route = Σ(占比 × 各级速度中值)
4. 与轨迹中位速度互验：若 v_route 与轨迹中位偏差 >20%，优先怀疑 T 级构成判错（常见：把成熟古道误判 T3、把石海段误判 T3）
